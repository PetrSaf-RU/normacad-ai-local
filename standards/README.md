# Локальная нормативная база NormaCAD AI

`catalog/eskd_manifest.csv` содержит проверенные карточки официального портала
Росстандарта. Карточка подтверждает обозначение, название, статус и область
применения, но не заменяет полный текст стандарта и не дает права придумывать
номера пунктов.

Полные тексты добавляются только из официально доступных документов:

1. Откройте карточку на `https://protect.gost.ru`.
2. Используйте официальный просмотр или скачивание документа.
3. Сохраните полученный PDF/HTML/TXT в `standards/inbox`.
4. Запустите `tools/import-standards.ps1`.

Сервис сохраняет SHA-256 и индексирует текст локально в SQLite FTS. Если
полнотекстовый фрагмент не найден, модель обязана сообщить об этом и оставить
вывод на ручную проверку.

Проверка доступности официальных карточек:

```powershell
.\tools\audit-rosstandart-catalog.ps1
```

Отчет сохраняется в `standards/catalog/rosstandart-audit.csv`.

Для советских чертежей храните как актуальный стандарт, так и историческую
редакцию, действовавшую на дату выпуска документа. Соответствие современной
редакции и историческая корректность — разные режимы проверки.
